# Codexpet

A collection of custom pets I created for Codex.

This repository is used to store and share my Codex pet assets, including pet configuration files, animation spritesheets, preview images, and future pet updates.

## Contents

Each pet should have its own folder, for example:

```text
pets/
  pet-name/
    pet.json
    spritesheet.png
    preview.png
```

## Usage

1. Download or clone this repository.
2. Open the folder for the pet you want to use.
3. Copy the pet files into your Codex pet directory.
4. Select the pet in Codex settings.
5. If the pet does not appear immediately, restart Codex and try again.
